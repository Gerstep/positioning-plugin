# Proof check — the 90-day window

Run against an existing `positioning/positioning.md`. About 10 minutes. The
brand that compounds proof feels inevitable, and the brand that feels
inevitable takes the market — this is where you check the compounding.

## Steps

1. Read the pack. Note its timestamp and the three proofs with dates.

2. **Proofs.** For each: shipped, slipped, or dead? If web access is
   available, verify shipped proofs publicly — announcement, changelog,
   press. A proof that shipped but was never announced is a wasted round:
   flag it.

3. **Mind-virus adoption.** If web access is available, search for the
   phrase. Who besides the company says it — customers, partners, media? The
   position is working when the market repeats it without you in the room.
   Zero echo early is normal; three months of zero echo means rewording or
   louder repetition.

4. **Category joiners** (create path only). Who else entered or started using
   the category language? A category of one a year in is failure. If nobody
   joined, the pack needs a plan to recruit players into the category — or an
   honest downgrade from create to reframe.

5. **First → best check** (create path only). More players plus someone
   redefining "best" means the FIRST framing has expired. Propose the
   ONLYness rewrite.

6. **Update the pack.** Mark proof statuses, append a dated check-in entry,
   and book the next three proofs — rolling thunder, each louder than the
   last. Statement changes require the user's explicit yes. Corrections
   append; they do not erase.
