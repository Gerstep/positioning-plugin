# Compile — collide the founders' answers

Run when two or more `positioning/answers-*.md` files exist. Whoever runs
compile is the tiebreaker of record — say so up front.

## Steps

1. Read every answers file. Read `positioning/research.md` if present. If
   research never ran, run it now per `references/research.md` — compile has
   no 15-minute cap, but stay tight.

2. Build four maps, in this order, and show them:

   - **Agreement** — where founders independently match. These are real; they
     anchor the pack.
   - **Contradiction** — where they diverge: different path, different ICP,
     different enemy, different value prop. Each contradiction is a strategic
     decision nobody has made yet.
   - **Surprise** — something one founder said that nobody else did but is
     clearly right. Call it out by name.
   - **Gap** — questions nobody answered well. That signals the team hasn't
     thought it through. List gaps as open work; don't paper over them.

3. **Force the tiebreaks.** Present each contradiction as a binary choice with
   the tradeoff stated in one line each way. The runner decides now, or
   explicitly defers with "decide together by [date]". A deferred decision
   goes in the pack as an open decision — never as a fudge that includes both
   options.

4. Generate `positioning/positioning.md` from `assets/pack-template.md`. Run
   the skeptic pass from the session script on the final statement — claims
   survive or become dated bets in the 90-day plan.

5. **Draft vs final.** Show every founder's verbatim statement side by side
   with the final, plus 1–2 sentences on what changed and why. Do not soften
   whose framing lost.

## Rules

- Never average contradictory answers into mush. Pick or defer, visibly.
- An answer marked `low-confidence` loses ties against a confident one.
- If founders disagree on the *category path* itself, that is the first
  tiebreak — everything downstream depends on it.
- Take each founder's proofs into the same 90-day table; dedupe, keep the
  three loudest, sequence them.
